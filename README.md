## 发生了什么

2026-11-25 下午三点多，张雨鑫在校园内正常学习、编写代码时突发晕倒，由辅导员紧急送往**长沙市中心医院**抢救

- **抢救经过**：历经近 4 小时全力抢救才恢复心跳，随后转入急诊 ICU 重症监护室，目前已紧急启用 **ECMO（人工肺）** 维持生命体征
- **主要诊断**：呼吸心跳骤停（心源性可能性大）、心肺复苏后缺氧缺血性脑病、心律失常、代谢性酸中毒、高乳酸血症、心肌损害、肝功能不全、横纹肌溶解症等，多器官受损，生命体征仍极不稳定
- **费用困境**：
  - ECMO 开机费用约 **6–7 万元**
  - 每日运转、监护、用药及抢救费用高达 **1–2 万元**
  - **目前无医保可供报销**，全部治疗费用需由家庭全额自费承担
  - 其父母（张顺昌、陈媛美）来自广西玉林市陆川县滩面镇，常年在工地打零工维生，积蓄与亲友借款已在短短数日内耗尽
