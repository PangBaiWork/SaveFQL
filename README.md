## 关于他

张雨鑫（[@fuqiuluo](https://github.com/fuqiuluo)，社区里大家常叫他**伏秋洛**）今年 22 岁，是湖南中南林业科技大学的大四在读学生，也是活跃在 QQBot 开源社区与移动安全领域的年轻开发者。

他家庭条件很苦，父母（张顺昌、陈媛美）来自广西玉林市陆川县滩面镇，常年在工地打零工维生。靠着自己的拼命努力，他主攻 Android 逆向、内核开发与移动安全，先后在字节跳动、阿里巴巴实习，并且**已经成功拿到了阿里巴巴的转正 Offer**。

本来他美好的人生才刚刚要开始，但在 Offer 即将开奖的前一周，他在学校宿舍倒下了。

他在开源社区留下和参与过的部分项目：
- `unidbg-fetch-qsign` / `Shamrock`
- `ZygiskNext`
- [amice](https://github.com/fuqiuluo/amice)（基于 Rust 的 LLVM 混淆与指令级 VMP 框架）

大家熟知的 [go-cqhttp](https://github.com/Mrs4s/go-cqhttp)、[Lagrange.Core](https://github.com/LagrangeDev/Lagrange.Core)、[icqq](https://github.com/icqqjs/icqq) 等 QQBot 协议及其相关衍生开源项目，都离不开他背后挥洒的汗水。

## 事发经过

- 11 月 25 日下午三点多，张雨鑫在学校宿舍时突发心源性猝死晕倒。

- 在场室友第一时间对他进行了紧急心肺复苏（CPR），随后由辅导员紧急送往**长沙市中心医院**抢救。  
- 在医院历经近 4 个小时的全力抢救，他的心跳才得以恢复，随后被转入急诊 ICU 重症监护室，目前已紧急启用 **ECMO（人工肺）** 维持生命体征。  
- 目前医院诊断为：**呼吸心跳骤停（心源性可能性大）、心肺复苏后缺氧缺血性脑病**、心律失常、代谢性酸中毒、高乳酸血症、心肌损害、肝功能不全、横纹肌溶解症等。由于多器官受损，目前他的生命体征依然极不稳定，随时面临危险。
- ECMO 光开机费用就要 **6–7 万元**，加上 ICU 每日的运转、监护、用药及抢救，每天的费用高达 **1–2 万元**。
- 更加雪上加霜的是，**目前无医保可供报销**，所有治疗费用全部需要家庭自费承担。
- 常年在工地打零工的父母，在出事后的短短几天内就已经耗尽了家里全部积蓄和亲友借款，面对 ICU 每天上万元的账单已彻底无力支撑。
